# Security Policy

## Reporting a vulnerability

Report security issues privately by email to `hazem.ataya@hapesolutions.com`.

Do not open a public GitHub issue for a vulnerability.

Include:

- Affected command, API path, or module when known.
- Reproduction steps that do not include live secrets.
- Impact and any suggested mitigation.

## Expected handling

The maintainer will acknowledge private reports and decide on a fix path.

Do not disclose the issue publicly until a fix is released or the maintainer confirms disclosure is acceptable.

## Secrets

Never commit tokens, keys, passwords, or private endpoints.

If you discover a secret in the public tree or git history, rotate or revoke the credential first, then report it privately.
