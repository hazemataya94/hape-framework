# Code of Conduct

## Purpose

This project is a public automation toolkit.

Maintainers and contributors treat each other with professional respect.

## Expected behavior

- Keep discussion technical and specific.
- Assume good intent.
- Prefer evidence over speculation.
- Respect security-reporting boundaries in `SECURITY.md`.

## Unacceptable behavior

- Harassment, personal attacks, or discriminatory language.
- Publishing private information or credentials.
- Opening public issues that disclose unfixed security vulnerabilities.

## Enforcement

The maintainer may reject comments, close issues, or refuse pull requests that violate this code.

Contact `hazem.ataya@hapesolutions.com` for conduct reports that should stay private.
