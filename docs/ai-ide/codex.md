# Codex

## Install

1. Open the project root that Codex should read.
2. Create or edit `AGENTS.md`.
3. Merge the contents of `docs/ai-ide/templates/codex/AGENTS.md` into a HAPE section.
4. Keep any existing non-HAPE instructions above or below that section.

## Verify

Start a Codex session and ask which file contains HAPE safety rules.

Expected: `docs/llm/safety-policy.md` and `docs/llm/tool-contract.md`.

## Update

Replace only the HAPE section with the current template.

## Remove

Delete the HAPE section from `AGENTS.md`.
